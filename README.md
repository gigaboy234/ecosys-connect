# EcoSys Connect

Telegram-бот для знакомства студентов, стартапов, преподавателей и индустриальных партнёров.

## Роли

- **Студент** — ищет проект, команду или наставника
- **Стартап** — ищет сотрудников и экспертов
- **Преподаватель** — ищет проекты для руководства или консультирования
- **Индустриальный партнёр** — ищет стартапы для акселерации или студентов для стажировок

## Стек

- Python 3.11+
- aiogram 3.x
- SQLite (MVP) / PostgreSQL
- Redis (сессии и уведомления)

## Запуск

```bash
cp .env.example .env
# заполни BOT_TOKEN в .env
pip install -r requirements.txt
python bot/main.py
```
